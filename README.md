# Zepto SQL Project

## Project Overview
This project analyzes Zepto's inventory dataset using SQL to uncover business insights related to pricing, discounts, inventory management, and product categories.

## Objectives
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Category performance analysis
- Discount analysis
- Premium product identification
- Inventory insights

## Tools Used
- POSTGRESQL
- SQL
- GitHub

## Dataset
Zepto inventory dataset

├── data/
├── sql/
│   ├── data_cleaning.sql

│   └── business_queries.sql
├── outputs/
├── README.md

## Key Insights
- Highest discounted categories
- Premium product segments
- Out-of-stock analysis
- Inventory optimization opportunities
